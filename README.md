moment before it breaks production on a Friday. The agent has no weekends,
so Friday is just a word to it — and it ships at 4:59 PM while wishing the
humans a nice weekend.

Entry text (104 characters, one line):

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (pass `--out <dir>` to write
somewhere else for a local test run). Node 22.18+ required; standard
library only, deterministic, no network.
